# LEXICA(レキシカ) ─ 旧 タンゴクエスト (TangoQuest)

英単語を覚えるほど強くなる、**英単語×ローグライクRPG** の Web アプリ(PWA)。

[tango](https://github.com/zuno1000/tango)(英検1級 4択クイズ)の拡張プロジェクト。クイズ部分は tango の忘却曲線SRSをそのまま継承し、ゲームレイヤーを追加した。サーバー不要・完全無料・データは端末内 localStorage のみ。

## 遊びかた(コアループ)

1. **学習**: 4択クイズ(英検1級レベル・忘却曲線で出題)。**正解した単語はアイテムカードになる**
2. **カード**: 単語の品詞がカードの役割を決める
   | 品詞 | 役割 | 効果 |
   |---|---|---|
   | 名詞 | 装備(武器/防具/装飾品) | ステータス固定値の増加 |
   | 形容詞 | 強化 | 基礎ステータスの%バフ |
   | 副詞 | フィールド | 場全体の効果(全ステ%/技発動率/獲得ゴールド) |
   | 動詞 | 攻撃技 | オート戦闘中に確率で発動する大ダメージ |
3. **冒険**: キャラにカードを装備してダンジョンをオート攻略。クリアで🪙(恒常召喚のコイン)がたくさん手に入る
4. **ガチャ**(v4.6.0で通貨を分離): **恒常召喚=🪙(冒険・任務で入手)/期間限定召喚=🎫(クイズの正解1問で🎫1 ─ 学習だけが源泉)**。限定は常時2バナー開催・各バナーは14日周期で1週ずれて自動更新
5. さらに難しいダンジョンへ → もっとクイズを解いてカードを集める → …

### 仕掛け

- **学習ペース管理(v4.7.0〜)**: 「いつまでに全単語を覚えるか」の目標日を決めると、直近100問の結果(既知語率・復習正答率)から**1日の問題数の目安を毎日逆算**し、ホーム・学習画面のメーターで案内。新規単語の導入ペースも目標日から逆算される
- **リベンジドロップ**: 間違え続けた単語を(久しぶりに)正解すると、そのカードは通常より強力(★2〜★5)。間違え続けたほど強い
- **カードの重ね(v4.0.0〜)**: 同じカードを入手するたび Lv+1(Lv=枚数-1・上限なし)。旧「2枚合成で+1」は廃止し、既存の+Lvは枚数(2^lv)に自動換算
- **単語=1カード(v4.8.0〜)**: 同じ単語はレア度が違っても1枚のカードに合流(レア=最高到達・Lv=全レア合計枚数-1)。より高いレアを引くとカードが★ランクアップ。保存形式(`en|rar|0`→枚数)は不変で、表示層が毎回導出する
- **無限回廊**: 出発すると1階25秒で自動探索(放置)。クイズを解いている間も進む。10階ごとに🪙1000
- **ログインボーナス / デイリー・ウィークリー任務 / 実績**(段階制)

## 端末間同期(Googleドライブ・任意)

todaybgm と同方式(GIS + `drive.appdata` = 非機密スコープで審査不要)。

1. GCP でプロジェクト作成 → OAuth クライアントID(Webアプリ)を発行
   - 承認済みJS生成元: 本番URL(と開発用に別クライアントで `http://localhost:8000`)
2. `js/sync.js` の `GOOGLE_CLIENT_ID_PROD` / `GOOGLE_CLIENT_ID_DEV` に設定
3. アプリの ⚙ 設定 → 「今すぐ同期」(一度同期した端末は以後**自動同期**=v5.19.0)

**自動同期(v5.19.0)**: 一度同期した端末は、アプリを開いた直後に静かに同期する(手元にトークン(1時間有効)があるとき。別の端末に新しい記録がなければリロードせず、あれば取り込んでリロード)。トークンがない起動(ふつうは日をまたいだ起動)では、ユーザー操作なしの認証ポップアップがブラウザに止められるため、次の「学習/セットのつづき」タップで同期し、リロード後に学習タブへ自動で戻る。最終同期から5分以内・学習タブ表示中・オフラインでは何もしない(`autoSyncDecision`・純関数)。

**学習を終えたときの同期(v5.29.0)**: 学習タブから別のタブへ移る瞬間(`switchTab`)に、その滞在中に1問以上解いていれば(`syncNoteAnswer`で数える)同期する(`leaveSyncDecision`・純関数。最終同期からの間隔は問わない・未設定/未認証/オフライン/同期中は何もしない)。タブのタップ=ユーザー操作ありなので認証ポップアップも通る。別の端末に新しい記録があれば取り込んでリロードし、移った先のタブに戻る。代わりに、セット完了・にがて特訓完了・模試完了の画面の「📥 いま同期する」ボタン(v5.16.0)は廃止。

マージは「進捗を失わない方向」(単語記録=最後に解いた時刻が新しい方、カード在庫=多い方、通貨・実績=大きい方、なかま=和集合)で冪等。将来のバージョンが追加するフィールド(未知キー)も保持する(前方互換)。「データをすべてリセット」はリセット世代印(`resetAt`)を同期し、新しい世代が丸ごと勝つことで他端末からの復活を防ぐ(=リセットは全端末に伝播する)。

## プライバシー

サーバーには何も送信しない。学習・ゲームデータは端末内 localStorage のみ(同期を有効にした場合のみ、ユーザー自身のGoogleドライブのアプリ専用領域に保存)。「今日の英語」の記事一覧の取得だけは、公開フィードのURLを無料のCORS中継(rss2json / allorigins)経由で読む(学習データは送らない)。「マイ単語」の意味の自動取り込みは、登録した英単語だけを無料の翻訳エンドポイント(clients5.google.com / api.mymemory.translated.net)に送る(それ以外は送らない)。
