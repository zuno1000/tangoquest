# LEXICA(レキシカ) ─ 旧 タンゴクエスト (TangoQuest)

英単語を覚えるほど強くなる、**英単語×ローグライクRPG** の Web アプリ(PWA)。

[tango](https://github.com/zuno1000/tango)(英検1級 4択クイズ)の拡張プロジェクト。クイズ部分は tango の忘却曲線SRSをそのまま継承し、ゲームレイヤーを追加した。サーバー不要・完全無料・データは端末内 localStorage のみ。

## いまの姿(v5.13.0〜: 英単語アプリに絞る)

ゲーム面(編成・冒険=サバイバー・ガチャ・カード・任務)は `js/state.js` の **`GAME_ENABLED=false`** で非表示にしている(ユーザー決定「学習タブが洗練されて必要性が薄れた」)。コードとデータ(`G.inv`/`G.chars`/`G.gold`/`G.tickets`/`G.daily`…)はそのまま残り、カードの記録も裏で続くので、`true` に戻せば即復活する(`SLOT_ENABLED`・`SPEAK_ENABLED` と同じ可逆設計)。

## 遊びかた(コアループ)

1. **学習**: 4択クイズ(英検1級レベル・忘却曲線で出題)。**正解した単語はアイテムカードになる**
2. **カード**: 単語の品詞がカードの役割を決める
   | 品詞 | 役割 | 効果 |
   |---|---|---|
   | 名詞 | 装備(武器/防具/装飾品) | ステータス固定値の増加 |
   | 形容詞 | 強化 | 基礎ステータスの%バフ |
   | 副詞 | フィールド | 場全体の効果(全ステ%/技発動率/獲得ゴールド) |
   | 動詞 | 攻撃技 | オート戦闘中に確率で発動する大ダメージ |
3. **冒険**: キャラにカードを装備してダンジョンをオート攻略。クリアで🪙(恒常召喚のコイン)がたくさん手に入る
4. **ガチャ**(v4.6.0で通貨を分離): **恒常召喚=🪙(冒険・任務で入手)/期間限定召喚=🎫(クイズの正解1問で🎫1 ─ 学習だけが源泉)**。限定は常時2バナー開催・各バナーは14日周期で1週ずれて自動更新
5. さらに難しいダンジョンへ → もっとクイズを解いてカードを集める → …

### 仕掛け

- **学習ペース管理(v4.7.0〜)**: 「いつまでに全単語を覚えるか」の目標日を決めると、直近100問の結果(既知語率・復習正答率)から**1日の問題数の目安を毎日逆算**し、ホーム・学習画面のメーターで案内。新規単語の導入ペースも目標日から逆算される
- **リベンジドロップ**: 間違え続けた単語を(久しぶりに)正解すると、そのカードは通常より強力(★2〜★5)。間違え続けたほど強い
- **カードの重ね(v4.0.0〜)**: 同じカードを入手するたび Lv+1(Lv=枚数-1・上限なし)。旧「2枚合成で+1」は廃止し、既存の+Lvは枚数(2^lv)に自動換算
- **単語=1カード(v4.8.0〜)**: 同じ単語はレア度が違っても1枚のカードに合流(レア=最高到達・Lv=全レア合計枚数-1)。より高いレアを引くとカードが★ランクアップ。保存形式(`en|rar|0`→枚数)は不変で、表示層が毎回導出する
- **無限回廊**: 出発すると1階25秒で自動探索(放置)。クイズを解いている間も進む。10階ごとに🪙1000
- **ログインボーナス / デイリー・ウィークリー任務 / 実績**(段階制)
- **フレーズ学習(v5.0〜)+ミックス(v5.10.0〜)**: 「日本語は出るが英語が出てこない」を解消する意図→英語の産出訓練(452フレーズ+マイフレーズ。v5.16.0で「論述・根拠」64文=英検1級の頻出トピックで主張+根拠を一文・10〜16語・答え合わせに論の運びの型)。出題は**並べ替え**に一本化(v5.15.0・`PHR_REORDER_ALL`=可逆)し、定着の階段は粒度で作る: チャンク(2〜3片)の並べ替え(定着0-1)→単語(3〜12語・論述・根拠は最大16語)の並べ替え(2-3)→「まず自力で英文を思い出す」→単語の並べ替え(4〜)。従来のクローズ4択・全文4択は🎯実戦ドリル(fmt固定)に残る。学習タブの既定は**ミックス**=30問セットの5問目ごとにフレーズが混ざる(セットの進みは単語+フレーズの合算・今日の目安は単語だけ)。🎯実戦ドリル(グラフ描写・大人の動詞・無生物主語・マイフレーズ特訓)はすべて選択式で、日替わりの「今日のドリル」がセット完了画面に出る。口頭ステージ・口頭ドリルは `js/phrase.js` の `SPEAK_ENABLED` で撤去中(trueで復活)
- **既定の出題そのものを賢く(v5.12.0・「学習」を押すだけで効率よく)**: ①復習の単語は選択肢を伏せて「まず自力で思い出す」ワンクッション(新規・にがて特訓・サバイバーでは出ない。フレーズと同じ `preRecall` 設定でオフ可) ②4択の誤答は「以前に取り違えた相手」(`G.conf`・両方向に記録)→「同じ語根の語」→無作為の順で生成(消去法で解けない) ③ミスの直後は取り違えた相手を数問以内に追い出題(`pairQueue`) ④マイ単語の新規導入は1セットに `MYW_PER_SET`=6語まで ⑤マイ単語に「出会った英文」を添えると答え合わせで表示。新しいモード・ボタンは増やさない方針
- **にがての立て直し(v5.10.0〜)**: ミスの直後、選んだ誤答の選択肢の右端に「その意味を持つ単語」(v5.11.0・正解側の「次へ ▶」と同じ位置)、結果バーに「同じ語根の覚えた仲間」を手がかりとして表示。正誤確認中は正解の選択肢をタップしても次へ進める。⚙設定・記録の「🔥にがてノート」は並びの基準(ミスが多い/連続ミス中/定着が低い/復習が近い)を選べ、その上位だけの短い特訓(10問)を始められる。セット完了画面には「このセットのミス◯語を立て直す」
- **マイ単語(v5.11.0)**: 記事を読んでいて分からなかった単語を貼るだけで登録(学習タブの➕・今日の英語・⚙設定から。1行1語・「単語 — 日本語」なら意味も同時に)。句動詞・慣用表現(put up with・in tandem・what if・rule of thumb など6語まで)も登録でき、品詞は先頭の語から推定(動詞+小辞=動詞/前置詞句・つなぎの表現=副詞/名詞句=名詞・v5.11.1)。意味は無料の翻訳エンドポイント(Google翻訳の辞書拡張用→MyMemory・単語だけを送る)で**後から自動で取り込み**、取れない語は「意味待ち」として残して再挑戦(LLMに頼む依頼文もある)。登録した語は `WORDS` に合流して内蔵語と同じSRS・カード・図鑑に乗り、未出題のうちは新規の中で優先して出る。内蔵に同じ語があれば優先出題の印だけ付く。`js/myword.js`
- **今日の英語(v5.10.0)**: 英検1級(CEFR C1)レベルの英語メディア(記事23誌・ポッドキャスト/YouTube50番組・`js/reading.js` のカタログ。**全文を無料で読める・全編を無料で視聴できるソースだけ**=有料・閲読制限のあるメディアは載せない。会員限定の記事が混ざっていたVox・Big Thinkは`pay:1`で候補から外す=v5.23.0)から、読む・聴くを毎日1本ずつおすすめ。推薦は端末内の純関数(興味のテーマで重み付け・合わないソースは除外・昨日/一昨日に出したソースは後ろ・日付ハッシュで決定的)。**今日の1本はその日はじめて開いたときに決めて保存**(`G.rl.pick`・v5.19.0: 閉じても・別の端末でも同じ1本。「別の候補」に進めた先も保持。日付が変われば更新)。**聴くは「⏱ 長さ」(〜5分・〜15分・〜30分・既定15分・`G.rl.lmax`)以内の回だけ**(v5.23.0。フィードの`itunes:duration`で絞り、長さのないYouTubeはチャンネルの典型的な長さ`typ`で判定。1回がほぼ常に30分超の番組・長い動画が混ざるチャンネルは`long:1`で候補から外す。短い番組=NPR News Now・Merriam-Webster Word of the Day・Consider This・Marketplace Morning Report・BBC Witness History)。フィードは無料のCORS中継(rss2json→allorigins→直接)で取り込み当日分をキャッシュ。解説・語彙・英検1級一次と同じ形式の問題(v5.24.0: 読解=Part 2空所補充2問+Part 3内容一致4問・リスニング=Part 2/4・過去問2025年度第2回〜2026年度第1回の形式に合わせた。v5.23.0以前はTrue/False/Not Given)・Part 4形式の要約(90〜110語・4観点の採点)・Part 5形式の英作文(200〜240語・理由3つ)/二次スピーチの添削などは各自のLLMに頼む方針で、題名とURL入りの依頼プロンプトをコピーできる(アプリ側で翻訳・問題生成はしない)。プロンプトは使う順(①4択→②解説/教材化→③要約の添削/ディクテーション→④意見を言う)に並び、モーダルの「📘 進め方」が学習の流れを案内(v5.11.0)。②の語彙一覧は「単語 — 日本語」の形式で返るのでマイ単語にそのまま貼れる

## 性能の決まりかた

カード性能は単語綴りの FNV-1a ハッシュから**決定的に**生成される(同じ単語は常に同じカード)。レア度倍率 ×1/1.6/2.5/3.8/5.5、重ねLvごとに +30%(+10 以降は35%効率で無限に伸びる)。キャラクターは全員が固有スキル(与ダメ/被ダメ/回復/ゴールド/XP等のパッシブ)を1つ持つ。

## 端末間同期(Googleドライブ・任意)

todaybgm と同方式(GIS + `drive.appdata` = 非機密スコープで審査不要)。

1. GCP でプロジェクト作成 → OAuth クライアントID(Webアプリ)を発行
   - 承認済みJS生成元: 本番URL(と開発用に別クライアントで `http://localhost:8000`)
2. `js/sync.js` の `GOOGLE_CLIENT_ID_PROD` / `GOOGLE_CLIENT_ID_DEV` に設定
3. アプリの ⚙ 設定 → 「今すぐ同期」(一度同期した端末は以後**自動同期**=v5.19.0)

**自動同期(v5.19.0)**: 一度同期した端末は、アプリを開いた直後に静かに同期する(手元にトークン(1時間有効)があるとき。別の端末に新しい記録がなければリロードせず、あれば取り込んでリロード)。トークンがない起動(ふつうは日をまたいだ起動)では、ユーザー操作なしの認証ポップアップがブラウザに止められるため、次の「学習/セットのつづき」タップで同期し、リロード後に学習タブへ自動で戻る。最終同期から5分以内・学習タブ表示中・オフラインでは何もしない(`autoSyncDecision`・純関数)。

マージは「進捗を失わない方向」(単語記録=最後に解いた時刻が新しい方、カード在庫=多い方、通貨・実績=大きい方、なかま=和集合)で冪等。将来のバージョンが追加するフィールド(未知キー)も保持する(前方互換)。「データをすべてリセット」はリセット世代印(`resetAt`)を同期し、新しい世代が丸ごと勝つことで他端末からの復活を防ぐ(=リセットは全端末に伝播する)。

## プライバシー

サーバーには何も送信しない。学習・ゲームデータは端末内 localStorage のみ(同期を有効にした場合のみ、ユーザー自身のGoogleドライブのアプリ専用領域に保存)。「今日の英語」の記事一覧の取得だけは、公開フィードのURLを無料のCORS中継(rss2json / allorigins)経由で読む(学習データは送らない)。「マイ単語」の意味の自動取り込みは、登録した英単語だけを無料の翻訳エンドポイント(clients5.google.com / api.mymemory.translated.net)に送る(それ以外は送らない)。
