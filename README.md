# LEXICA(レキシカ) ─ 旧 タンゴクエスト (TangoQuest)

英単語を覚えるほど強くなる、**英単語×ローグライクRPG** の Web アプリ(PWA)。

[tango](https://github.com/zuno1000/tango)(英検1級 4択クイズ)の拡張プロジェクト。クイズ部分は tango の忘却曲線SRSをそのまま継承し、ゲームレイヤーを追加した。サーバー不要・完全無料・データは端末内 localStorage のみ。

## 遊びかた(コアループ)

1. **学習**: 4択クイズ(英検1級レベル・忘却曲線で出題)。**正解した単語はアイテムカードになる**
2. **カード**: 単語の品詞がカードの役割を決める
   | 品詞 | 役割 | 効果 |
   |---|---|---|
   | 名詞 | 装備(武器/防具/装飾品) | ステータス固定値の増加 |
   | 形容詞 | 強化 | 基礎ステータスの%バフ |
   | 副詞 | フィールド | 場全体の効果(全ステ%/技発動率/獲得ゴールド) |
   | 動詞 | 攻撃技 | オート戦闘中に確率で発動する大ダメージ |
3. **冒険**: キャラにカードを装備してダンジョンをオート攻略。クリアで🪙(恒常召喚のコイン)がたくさん手に入る
4. **ガチャ**(v4.6.0で通貨を分離): **恒常召喚=🪙(冒険・任務で入手)/期間限定召喚=🎫(クイズの正解1問で🎫1 ─ 学習だけが源泉)**。限定は常時2バナー開催・各バナーは14日周期で1週ずれて自動更新
5. さらに難しいダンジョンへ → もっとクイズを解いてカードを集める → …

### 仕掛け

- **学習ペース管理(v4.7.0〜)**: 「いつまでに全単語を覚えるか」の目標日を決めると、直近100問の結果(既知語率・復習正答率)から**1日の問題数の目安を毎日逆算**し、ホーム・学習画面のメーターで案内。新規単語の導入ペースも目標日から逆算される
- **リベンジドロップ**: 間違え続けた単語を(久しぶりに)正解すると、そのカードは通常より強力(★2〜★5)。間違え続けたほど強い
- **カードの重ね(v4.0.0〜)**: 同じカードを入手するたび Lv+1(Lv=枚数-1・上限なし)。旧「2枚合成で+1」は廃止し、既存の+Lvは枚数(2^lv)に自動換算
- **単語=1カード(v4.8.0〜)**: 同じ単語はレア度が違っても1枚のカードに合流(レア=最高到達・Lv=全レア合計枚数-1)。より高いレアを引くとカードが★ランクアップ。保存形式(`en|rar|0`→枚数)は不変で、表示層が毎回導出する
- **無限回廊**: 出発すると1階25秒で自動探索(放置)。クイズを解いている間も進む。10階ごとに🪙1000
- **ログインボーナス / デイリー・ウィークリー任務 / 実績**(段階制)
- **フレーズ学習(v5.0〜)+ミックス(v5.10.0〜)**: 「日本語は出るが英語が出てこない」を解消する意図→英語の産出訓練(388フレーズ+マイフレーズ)。出題は定着の階段と連動: 核のクローズ4択(定着0-1)→並べ替え(2-3)→全文4択(4〜)。学習タブの既定は**ミックス**=30問セットの5問目ごとにフレーズが混ざる(セットの進みは単語+フレーズの合算・今日の目安は単語だけ)。🎯実戦ドリル(グラフ描写・大人の動詞・無生物主語・マイフレーズ特訓)はすべて選択式で、日替わりの「今日のドリル」がセット完了画面に出る。口頭ステージ・口頭ドリルは `js/phrase.js` の `SPEAK_ENABLED` で撤去中(trueで復活)
- **にがての立て直し(v5.10.0)**: ミスの直後に「選んだ誤答」と「同じ語根の覚えた仲間」を手がかりとして表示。正誤確認中は正解の選択肢をタップしても次へ進める。⚙設定・記録の「🔥にがてノート」からミスの多い語だけの短い特訓(10問)を始められ、セット完了画面には「このセットのミス◯語を立て直す」
- **今日の英語(v5.10.0)**: 英検1級(CEFR C1)レベルの英語メディア(記事25誌・ポッドキャスト/YouTube45番組・`js/reading.js` のカタログ。**全文を無料で読める・全編を無料で視聴できるソースだけ**=有料・閲読制限のあるメディアは載せない)から、読む・聴くを毎日1本ずつおすすめ。推薦は端末内の純関数(興味のテーマで重み付け・合わないソースは除外・直近3日は後ろ・日付ハッシュで決定的)。フィードは無料のCORS中継(rss2json→allorigins→直接)で取り込み当日分をキャッシュ。解説・語彙・内容正誤問題・要約の添削などは各自のLLMに頼む方針で、題名とURL入りの依頼プロンプトをコピーできる(アプリ側で翻訳・問題生成はしない)

## 性能の決まりかた

カード性能は単語綴りの FNV-1a ハッシュから**決定的に**生成される(同じ単語は常に同じカード)。レア度倍率 ×1/1.6/2.5/3.8/5.5、重ねLvごとに +30%(+10 以降は35%効率で無限に伸びる)。キャラクターは全員が固有スキル(与ダメ/被ダメ/回復/ゴールド/XP等のパッシブ)を1つ持つ。

## デプロイ(Cloudflare Pages)

1. Cloudflare ダッシュボード → Workers & Pages → Pages → 「Gitに接続」→ このリポジトリを選択
2. ビルド設定なし(静的サイト)・出力ディレクトリ `/`
3. `_headers` の CSP は **Report-Only で観察 → 違反ゼロを確認してから強制化**(todaybgm と同運用)

## 端末間同期(Googleドライブ・任意)

todaybgm と同方式(GIS + `drive.appdata` = 非機密スコープで審査不要)。

1. GCP でプロジェクト作成 → OAuth クライアントID(Webアプリ)を発行
   - 承認済みJS生成元: 本番URL(と開発用に別クライアントで `http://localhost:8000`)
2. `js/sync.js` の `GOOGLE_CLIENT_ID_PROD` / `GOOGLE_CLIENT_ID_DEV` に設定
3. アプリの ⚙ 設定 → 「今すぐ同期」

マージは「進捗を失わない方向」(単語記録=解答回数が多い方、カード在庫=多い方、通貨・実績=大きい方、なかま=和集合)で冪等。将来のバージョンが追加するフィールド(未知キー)も保持する(前方互換)。「データをすべてリセット」はリセット世代印(`resetAt`)を同期し、新しい世代が丸ごと勝つことで他端末からの復活を防ぐ(=リセットは全端末に伝播する)。

## プライバシー

サーバーには何も送信しない。学習・ゲームデータは端末内 localStorage のみ(同期を有効にした場合のみ、ユーザー自身のGoogleドライブのアプリ専用領域に保存)。「今日の英語」の記事一覧の取得だけは、公開フィードのURLを無料のCORS中継(rss2json / allorigins)経由で読む(学習データは送らない)。
